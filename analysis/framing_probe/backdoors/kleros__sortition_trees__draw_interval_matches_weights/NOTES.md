In `draw`, the left-subtree leaf choice uses `ticket <= leaf0Value` instead of `ticket < leaf0Value`, so a ticket exactly equal to leaf 0's weight is assigned to leaf 3 instead of leaf 4. Counterexample: rootSum = 10, leftSum = 5, leaf0 = 2 (others 0), ticket = 2. The requires pass (root != 0, 2 < 10); since 2 < leftSum and leaf0 <= 2, the spec demands selectedNode = 4, but the contract stores 3.
