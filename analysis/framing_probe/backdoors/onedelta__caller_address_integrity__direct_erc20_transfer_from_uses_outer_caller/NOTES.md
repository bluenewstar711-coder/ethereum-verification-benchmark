In `_transferFrom`, the pull address falls back to `msg.sender` when `callerAddress` is the zero address (`let from_ := ite (callerAddress == 0) sender callerAddress`), rather than always using the forwarded outer caller. Counterexample: callerAddress = 0 and a state whose msg.sender is address 1. The ERC20 pull is recorded (erc20PullOccurred = 1) with from-word addressToWord 1, but the spec, evaluated with sender := callerAddress, requires addressToWord 0, so `erc20_caller_spec` fails.
